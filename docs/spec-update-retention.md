## 1. Діагноз (стисло, з доказами)

Бій і джус — сильні (damage-числа, hitstop, вібро, комбо, конфетті — `effects.js`, `hud.js:242-262`). Гра програє НЕ в бою, а навколо нього:

1. **Краї петлі діряві.** Екран перемоги має одну кнопку «🌍 На глобус» (`index.html:257-265`) — після піку конфетті гравця викидає в меню. Екран смерті — пасивний відлік без «Реванш» (`index.html:249`, `main.js:3160`). Стартовий глобус голий: компас `_playerCompassHtml()` (`main.js:1197`) рендериться лише всередині меню ГРАТИ, welcome-back немає взагалі (`main.js:1066-1087`).
2. **Нуль re-engagement.** У коді немає жодного streak/подарунка дня/тосту «новий день» (grep по `src/` порожній). Daily-квести генеруються тихо (`progress.js:375-420`). Компас `_nextActionInfo()` (`main.js:1151-1195`) НЕ знає про квести дня, а після «світ врятовано» каже буквально «Спробуй Шторм» — глухий кут.
3. **Прогресія скінченна, валюти мертві.** Пас 65 рівнів назавжди (`progress.js:77-105`). Усі 32 монетні товари скінченні → у ветерана монети нікуди дівати (`shop.js`). Титули бінарні, без прогрес-барів і «майже досяг» (`titles.js`, `main.js:1654`).
4. **Соціального шару нема.** Кооп-фундамент зрілий (реконекти, лінк-інвайти `coopui.js:164-194`, кампанія в коопі), але: нема командної ліги (`League` DO приймає лише соло storm/arena), нема нагороди «за гру разом», нема «хто сьогодні найкращий».
5. **Забіги схожі один на один.** Драфт «Прокачка» — 15-16 карт, лише 2 режими з ~15 (`runbuild.js`, `main.js:2530,2542`). Weekly-мутатор діє тільки в соло-реплеях кампанії (`main.js:2305`), бо кімнатні режими не використовують орду/магазин.
6. **Техборг:** зомбі-риги дають ~324 draw calls (живий UKR = 601 при бюджеті 450 у `mobile-perf.mjs`); `main.js` 4717 рядків / 109 методів; гілка CI-фіксів готова, але НЕ закомічена.

**Вердикт радника (прийнято):** Ф1+Ф2 — одним маленьким релізом і якнайшвидше; CI-мерж — до всього; спектатор-камеру і «недавніх друзів» викинути (не рухають метрику); мутатори — через ОДНУ точку перехоплення (`zombies.spawn`), не патчити 17 файлів режимів; ліга — окремий останній реліз (найбільший ризик утонути).

- **Констрейнти:** wire кооп-протоколу НЕ міняється (тільки HTTP League/Lobby API) → PROTO bump НЕ потрібен, але **деплой воркера обов'язковий** (`cd worker && npx wrangler deploy`); ліміти: `MAX_BODY_BYTES=4096`, нові поля клампити серверно (`_cleanProfile`-патерн); dev-relay і воркер ділять `worker/route.mjs` — деплоїти атомарно з релізом клієнта.
- **Верифікація:** кооп-тест проти dev-relay: два клієнти → сабміт → таблиця команд містить запис; кламп сміттєвих полів.

## 9. Наскрізні правила релізу (капкани, здобуті кров'ю)

1. Кожен реліз: бамп `version.json` + `APP_VERSION` (main.js) + `zr-cache-vNN` (sw.js); гейт `node test/version-sync.mjs`. PROTO_VERSION — лише при зміні wire (у цій спеці — ніде).
2. Новий `src/*.js` файл → рядок-літерал у `sw.js` SHELL (гейт `test/sw-cache.mjs`). Спека навмисно уникає нових файлів де можливо.
3. Тести з ТОЧНИМИ нагородами мокають `dailyChallengeId` І `weeklyChallengeId`; `progress.addXp` дає монети за рівні паса — ставити `xp=999999` перед лічбою монет.
4. Нові батарея-тести: `const SLOW=Math.max(1,parseFloat(process.env.SLOW||'1')||1)`, × SLOW на всі waitFor і in-page вікна.
5. Нові save-ключі → `SAVE_PROGRESS_KEYS` (`src/net/cloudsave.js:31`) + guarded-список `test/cloudsave.mjs`.
6. Повна батарея = `release.mjs` (~25 хв) + `test:coop-release` — ганяти частинами, EXIT-маркер у лог-файл; на macOS немає `timeout`.
7. Паралельні ШІ-сесії в теці — перед редагуванням перечитувати файли.
8. Червоні лінії: не видаляти оплачені анлоки; не чіпати анти-вогонь щит; жодного хижого FOMO (стрік без покарань, бокси без «майже виграв»).

## 10. Свідомо НЕ входить (щоб не втонути)

- Справжній InstancedMesh зомбі (L, окремий перф-трек після R2-кешу).
- Сезонний скид Зоряного шляху (капкан `grantBacklog`; престиж-сток закриває ту саму потребу дешевше).
- Кооп-мутатори тижня, розширення коопу на maze/worldboss, ролі/класи (усе = PROTO bump — окреме мережеве оновлення).
- Спектатор-камера, «недавні друзі», повний сезон ліги зі скиданням, нові режими-клони «кімната з хвилями».
- Розбиття `main.js`/`characters.js` — робити опортуністично, лише якщо задача R1-R5 і так торкається кластера.

## 11. Критерій успіху

Через 2 тижні після R1: стрік у сейві дитини і друзів ≥5 без нагадувань; «Ще раз/Далі» використовуються (видно по сесіях поспіль); через місяць — донат-зірки > 0 у ветеранів (монети знову потрібні).
