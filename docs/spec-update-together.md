## 3. R1 «Еліти разом» (v296, PROTO 11)

**Зараз**: елітною хвилю позначає missionpool.js:596 під `fresh && !level.net`; скриня хвилі main.js:3131 і золота скриня main.js:3147 — `if (level.net) return`.

**Зміни**:
- Позначка хвилі: гард `!level.net` → `(!level.net || level.net.authority)` — рішення приймає ХОСТ (у гостя-mirror ця гілка й так не бігає, але гард робимо явним).
- Спавн еліт: наявний `spawnEliteWave` (zombies.js:539) на хості; еліт-прапори вже їдуть гостям у `o` події `zs` (host.js:364–384) — перевірити, що ВСІ 4 типи (щитоносець/розділювач/підривник/золотий) відтворюються puppet'ом коректно (аура/іконка/поведінка розділювача при смерті — міні спавнить ХОСТ, гість лише бачить нові `zs`).
- Нові події ev: `ew` (старт хвилі: телеграф-банер + стінгер eliteWave() у ВСІХ) і `ewc` (хвилю зачищено). PROTO 11.
- Нагорода по `ewc`: КОЖЕН клієнт локально нараховує собі 120🪙 + 3💎 + свій незалежний рол шансу яйця 10% (патерн кооп-бонусу — без адресних грантів). Показ: неблокуючий банер зі складом нагороди, БЕЗ chestCeremony.
- Золотий у коопі: по `zd` з прапором golden хост шле `gch` → кожен нараховує 200🪙(перевірити соло-число в main.js:3147) + рол яйця 15%, банер. Соло-шлях не чіпати.
- Складність еліт масштабується наявним coopMul автоматично — окремих множників не вводити.

**Тести**: новий `test/coop-elite.mjs` (за шаблоном coop2): хост+гість → форс елітної хвилі тест-хуком → у гостя puppet-еліти з прапорами → банер `ew` на обох → зачистка → `ewc`, нагорода нарахована ОБОМ (гроші/кристали в сейвах обох) → mid-join посеред хвилі (coop3-патерн) не падає. Реєстрація в test/release.mjs.

## 4. R2 «Сила разом» (v297, PROTO 12)

**Зараз**: спавн main.js:3466 (`level.net` гард), активація main.js:3475, тригери main.js:3213/3216, клас SuperPickup — extras.js:151.

**Зміни**:
- Спавн вирішує хост (ті самі тригери: 2-га здана місія АБО старт елітної хвилі; гарди звузити до authority). Об'єкт отримує nid (`allocId()`), подія `spx`(nid,x,z) — гість малює дзеркальний SuperPickup (зірка+стовп світла).
- Підбір host-authoritative (шаблон лута effects.js:1685–1691): найближчий живий гравець у радіусі → хост ролить силу (🔥 Шквал / 🧲 Магніт-буря) → подія `spg`(nid, pid, power) + despawn на всіх.
- Застосування по `spg`: клієнт з моїм pid активує силу ЛОКАЛЬНО (наявний `_activateSuperPower`, слоу-мо і золотий спалах — ЛИШЕ в того, хто взяв); решта бачить банер «⭐ {нік} схопив ШКВАЛ!» + короткий стінгер.
- Магніт-буря: хостовий pickup-цикл (main.js:3296 getPickupTargets) враховує посилений радіус ЛИШЕ для pid з активною силою — хост тримає мапу pid→{power,ttl} (він сам джерело `spg`, тож знає). Клієнтський візуал-магніт у гостя вже net-обізнаний (effects.js:1653).
- Реконект: непідібраний супер → у `captureState`/`_applyState`; активна сила коротка — у state НЕ синкається (задокументувати в коді).
- Один супер на рівень — лічильник на хості.

**Тести**: `test/coop-super.mjs`: спавн видно обом → гість підбирає (навести гостя тест-хуком) → сила активна У ГОСТЯ (firerate/магніт), у хоста лише банер → монети з магніт-бурі гостя реально злітаються (хост-лут) → mid-join бачить непідібрану зірку. Реєстрація в release.mjs.

## 5. R3 «Зірки разом» (v298, PROTO 13)

**Зараз**: main.js:4999 — зірки лише при `secondaryObjective && !level.net`; вторинну ціль соло ролить на старті забігу.

**Зміни**:
- Вторинну ціль ролить ХОСТ на старті кооп-кампанійного рівня (від сіда кімнати) і передає у `start`/`cfg` (нове поле → PROTO 13). Чип цілі на HUD у ВСІХ.
- Прогрес цілі — КОМАНДНИЙ, рахує хост (убивства еліт/мегабокс/монети за забіг/хедшоти — з хостової симуляції), їде полем у `snap.m` або окремою подією `soc` при виконанні (тік+дзвіночок у всіх).
- Нарахування на netVictory КОЖНИМ локально: ⭐1 — перемога; ⭐2 — командна ціль виконана (`soc` було); ⭐3 — ОСОБИСТО жодної смерті за забіг (кожен рахує свої смерті локально). Пише у власний сейв через наявний stars.js — пороги 12/24/36, яйця-мілстоуни, лічильник ⭐X/36 працюють автоматично.
- Реплей — MAX-логіка та сама. Милосердя (mercy) лишається соло-only: у коопі тебе піднімає друг — це і є милосердя (задокументувати рішення в коді).
- Заражені/спецрежими зірок не дають (гейт secondaryObjective лише кампанія — як у соло v294).

**Тести**: `test/coop-stars.mjs`: обидва бачать один чип цілі → командне виконання → `soc` тік на обох → перемога → у ХОСТА ⭐≥2, у гостя, що вмирав, нема ⭐3, але є ⭐1/⭐2 → зірки в сейвах обох, реплей не забирає. Реєстрація в release.mjs.

## 6. R4 «Табір кличе» (v299, без PROTO)

### 6.1 Тижневий квест табору → 🥚
- У таборі бази (hqbase) при ≥1 врятованому другові з'являється дошка квесту (декор-меш + інтеракція, як «щоденне дякую»); на глобусі — маленький чип-нагадування, НЕ модалка.
- Квест тижня детермінований від week-key (той самий механізм, що coop-weekly): один із пулу «🧟 Здолай 15 елітних» / «🚁 Врятуй 25 людей» / «🏁 Пройди 3 країни» (числа збалансувати під ~2-3 сесії). Прогрес рахується і в соло, і в коопі (локальні події гравця).
- Нагорода: 🥚 яйце + 🍖×2, клейм на дошці (церемонія скрині — це мета-екран, можна). Квест НЕ згорає; наступного тижня — новий. Клейм минулого тижня доступний, поки не взято новий (без FOMO).
- Save: `weeklyCamp` (week-key, прогрес, claimed) → SAVE_PROGRESS_KEYS + guard cloudsave.mjs.

### 6.2 Черга банерів
- hud.banner → пріоритетна черга: banner(msg, {prio}) — критичні (хвиля, буря) показуються одразу, решта чекає; мінімальний показ ~1.6с, черга ≤3 (старіші низькопріоритетні витісняються). API викликів НЕ міняти — дефолтний prio зберігає поведінку.

### 6.3 hintOnce-онбординг
- Разові підказки (наявний механізм hintOnce): перший еліт на екрані, перший чип вторинної цілі, перша клітка друга в полі зору, перше відкриття альбому. Коротко, тепло, по-дитячому.

### 6.4 i18n-гейт
- Статичний скрипт `test/i18n-parity.mjs`: збирає всі літерали `t('…')` по src/ + index.html і звіряє з ключами en.js/ru.js; падає зі списком пропущених. Зареєструвати в release.mjs. Наявні пропуски виправити в цьому ж релізі.

**Тести**: `test/weekly-camp.mjs` (детермінізм week-key, прогрес соло+кооп, клейм, ретро-безпека), `test/banner-queue.mjs`, hintOnce — у наявний ux-тест, i18n-гейт сам собі тест.
