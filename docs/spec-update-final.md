## R2 (v303) «Світ врятовано» — фінал кампанії + профіль героя

### 2.1 🌍 Церемонія «СВІТ ВРЯТОВАНО!»
- **Тригер:** момент, коли `save.liberated` уперше покриває ВСІ 12 `CAMPAIGN_ORDER` (перевірка після нарахування перемоги у _showVictory/_grantVictory-потоці), АБО (ретро-ветеран) перший вхід на глобус із уже повним покриттям. Одноразово: `save.worldSaved = 1` (новий ключ у SAVE_PROGRESS_KEYS + cloudsave-guard).
- **Що бачить гравець:** повноекранний святковий оверлей (окремий `overlay-worldsaved`, стиль перемоги, поверх глобуса — НЕ поверх victory-екрана: якщо тригер із перемоги, показ ПІСЛЯ повернення на глобус, щоб не красти конфетті перемоги):
  - заголовок «🌍 СВІТ ВРЯТОВАНО!» + підзаголовок «Усі 12 країн вільні — і це зробив ти!»;
  - рядок цифр пригоди: 🌍 12/12 · ⭐ X/36 · 🤝 друзів X/12 · 🧟 переможено N;
  - нагорода: 💎 +50 + медаль «🌍 Рятівник світу» (`save.medals` push 'WORLD', показ у титулах/альбомі);
  - підказка-місток: «Відкрився 🦖 Загублений острів — знайди його на глобусі!» (острів уже відкривається за 12/12 — тепер про це кажемо вголос);
  - кнопка «🎉 Ура!» закриває; салют-burst конфетті при відкритті; audio.victory().
- **Кооп:** подія локальна (перевірка власного save після нарахування) — працює симетрично, нічого в протокол не додаємо.
- **Малюк-режим/тач:** оверлей звичайний DOM — працює всюди; кнопка велика.

### 2.2 🏅 Вкладка «Герой» в Альбомі (профіль героя)
- Перша вкладка альбому «🏅 Герой» (перед «Друзі»): картка-вітрина власного прогресу, БЕЗ нового екрана — реюз каркаса альбому:

  - ⭐ X/36 зірок кампанії (смужка);
  - 🌍 звільнено X/12 (смужка) + медалі (Глава 3, Рятівник світу — сірі силуети, якщо не здобуті);

  - активний титул (як у меню) + скільки титулів здобуто X/Y.
- Дані ВСІ вже в save/stats/progress — жодних нових ключів. Лічильники живі при кожному відкритті.
