# v609 «Бійці Експедиції» — дизайн

Дата: 2026-07-23  
Статус: погоджено користувачем через «сам додумай і роби вже»

## Мета

Розширити наявний вибір спеціалістів Експедиції до п’яти карток і додати
зрозумілу платну прокачку рівнів. Не вигадувати атаки, Super чи гаджети двох
нових бійців замість автора гри.

## Бійці

Наявні Захисник, Медик і Розвідник залишаються повністю ігровими.

Додаються:

- `Бастіон` (`bastion`) — клас `Танк`, іконка `🧱`;
- `Імпульс` (`impulse`) — клас `Контроль`, іконка `🌀`.

Для Бастіона та Імпульсу картки й профілі доступні одразу, але кнопка вибору
заблокована до появи авторських атаки, Super і гаджетів. Це не дозволяє
витратити валюту на неігрового персонажа або непомітно підмінити авторський
дизайн тимчасовою зброєю.

## Прокачка

Кожен боєць починає з рівня 1 безкоштовно.

| Новий рівень | Ціна |
|---|---:|
| 2 | 250 монет |
| 3 | 500 монет + 3 кристали |
| 4 | 1000 монет + 10 кристалів |
| 5 (макс.) | 2000 монет + 25 кристалів |

Кожен рівень після першого дає `+10%` до максимального HP і шкоди. Отже,
множник рівня дорівнює `1.0 / 1.1 / 1.2 / 1.3 / 1.4`.

Бонус застосовується лише в соло-Експедиції. Кооператив і протокол v23 не
змінюються, доки нові бойові набори не визначені.

## UI

Натискання будь-якої картки бійця відкриває окремий DOM-dialog:

- назва, клас і поточний рівень;
- точний бонус HP і шкоди;
- атака;
- Super;
- два слоти гаджетів;
- ціна наступного рівня або `МАКС. РІВЕНЬ`;
- кнопка `Обрати` для готових бійців.

Для двох нових бійців бойові слоти показують `Очікує твоєї ідеї`, а кнопки
вибору й купівлі вимкнені. Закриття та `Escape` повертають фокус на картку.

## Дані

До сейва додається:

```js
fighterLevels = {
  guard: 1,
  medic: 1,
  scout: 1,
  bastion: 1,
  impulse: 1,
}
```

Значення клампляться до цілих `1..5`. Відсутній ключ мігрує без зміни старого
прогресу. Купівля атомарно перевіряє обидві валюти, списує їх один раз і
зберігає сейв.

Наявна майстерність `specialistXp` не видаляється: вона й далі відповідає за
пасив і потужність Super трьох готових спеціалістів. Платний рівень окремо
посилює тільки HP і шкоду.

## Super

Влучання заряджають Super до 100%, після чого
гравець натискає `C` або наявну touch-кнопку Super.

## Перевірка

- pure unit test для списку п’яти бійців, санітизації, цін, купівлі та множника;
- browser test для профілю, недостатньої валюти, успішної купівлі, max-рівня,
  заблокованих Бастіона/Імпульсу та повернення фокусу;
- migration, cloud-save drift, i18n parity, version sync, PWA та quick-release.

## Не входить у v609

- авторські атаки, Super і гаджети Бастіона та Імпульсу;
- заміна зброї трьох наявних спеціалістів персональними атаками;
- нові мережеві поля або зміна `PROTO_VERSION`;
- застосування бійців поза Експедицією.
