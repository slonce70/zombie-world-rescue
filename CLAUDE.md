# Правила роботи в цьому репозиторії

## Тести: коротко і по суті

**Не запускати багатогодинні набори.** `npm run test:release` (187 тестів) і
`npm run test:coop-release` (26 кооп-тестів) виконуються 2–3 години на ноутбуці —
це марна трата часу в діалозі. Їх ганяє CI за `workflow_dispatch`.

Локально запускати лише **точкові тести, що стосуються зміни**:

```bash
node test/<конкретний-тест>.mjs      # 1–3 хв
node test/version-sync.mjs           # секунди
node test/i18n-parity.mjs            # секунди
node test/sw-cache.mjs               # секунди
```

Якщо зміна велика — швидше **перевірити в реальному браузері**, ніж ганяти
батарею: `npm run serve` (порт 8741) + `npm run relay` і подивитись руками.

Деплой блокують дві джоби CI — `quick` і `smoke` (`deploy-pages` має
`needs: [quick, smoke]`). Точний склад — у `.github/workflows/tests.yml`:

- `quick` (ліміт 12 хвилин, Chromium не ставиться) — секундні гейти без
  браузера й доменні юніти одним `node --test`. Новий чистий доменний
  юніт — сюди.
- `smoke` (ліміт 20 хвилин, з Chromium) — браузерні тести. Новий сюди лише
  якщо він укладається в хвилину.

Довгі браузерні й кооп-батареї лишаються ручними (`workflow_dispatch`):
`expedition`, `front`, `e2e`, `release-gate`, `coop-gate`.

## Червоний тест = регресія. Розбирайся, не списуй

**Відомого боргу більше немає** — 13.08.2026 усі 30 червоних файлів розібрано поштучно
(`.scratch/green-battery/`). Тому кожне нове падіння означає щось справжнє, і його
треба зрозуміти, а не пояснити «воно й було червоне».

Той старий список «червоне не з нашої вини» коштував дорого: під ним півроку лежали
**три справжні поламки, які бачила дитина** — компас переставав кликати у Глави 2-3
після кампанії, річки не мали берегів, клон бив на 3 замість обіцяних магазином 5.

Коли тест червоний, відповідай на одне питання: **тест відстав від свідомої зміни
гри — чи гра справді зламана?** Еталон для порівняння:

```bash
git worktree add /tmp/ref <коміт-де-було-зелено>
ln -sfn "$(pwd)/node_modules" /tmp/ref/node_modules
cd /tmp/ref && ZR_PORT=8751 node test/<тест>.mjs
```

`ZR_PORT` обовʼязковий: без нього два прогони на машині мовчки їдять ОДНЕ дерево, і
тест перевіряє чужі файли (так уже отримували хибний зелений). На комітах, старіших
за `3327072`, підтримки змінної немає — там треба `sed -i '' 's/port = 8741/port = 8751/'
test/_server.mjs`.

**Заборонено робити тест зеленим, вихолостивши його** — прибрати ассерт, замінити на
`assert.ok(true)`, розширити допуск, обгорнути в `try`. Це гірше за червоний тест: у
дитячій грі хибне відчуття безпеки дорожче за незручність. Якщо перевірка справді
застаріла — зніми її цілком і поясни чому.

Кожну правку доводь **на злам**: навмисно зламай поведінку в грі й переконайся, що тест
червоніє. Тест, який не падає ні на чому, — не тест (так знайшли муляж у `update6`:
перевірка «хвилі приходять» лишалась зеленою з повністю вимкненими хвилями).

Chromium для Playwright встановлений — браузерні тести стартують локально за хвилини.
Програмний рендер на Mac дає ~0.6 fps, тож таймаути можуть бути голодуванням по кадрах,
а не поламкою; перевіряй повторним прогоном у тиші. Більше **трьох** браузерних агентів
одночасно ноутбук не тягне.

## Реліз

- Версію бампити в трьох місцях одразу: `src/main.js` (`APP_VERSION`),
  `version.json`, `sw.js` (`CACHE`). Гейт — `node test/version-sync.mjs`.
- `PROTO_VERSION` у `src/net/protocol.js` бампиться разом з `APP_VERSION`,
  якщо змінився формат кооп-повідомлень.
- Нові ESM-модулі додавати в `SHELL` у `sw.js` — інакше офлайн зламається
  (`node test/sw-cache.mjs`).
- Нові рядки `t('…')` мусять зʼявитись у `src/i18n/en.js` і `src/i18n/ru.js`.
- GitHub Pages деплоїться автоматично при push у `main` після джоб `quick` і `smoke`.
  Cloudflare Worker (`worker/`) деплоїться **окремо** через `wrangler deploy`.
