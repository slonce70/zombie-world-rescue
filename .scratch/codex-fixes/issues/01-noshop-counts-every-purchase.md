# 01 — Ціль «Не купуй нічого» рахує будь-яку покупку

**What to build:** Вторинна ціль забігу «Не купуй нічого в магазині» зараз зараховується, навіть
якщо гравець купив півмагазину — бо забіговий лічильник рухається лише від ціни в МОНЕТАХ, а
коробки, скіни, гаджети, обмін валют і вся радіаційна вітрина коштують нуль монет (їхня ціна — у
кристалах або радіаційних монетах).

Після цього тікета ціль ламається від будь-якої успішної покупки, якою б валютою за неї не
платили. Гравець, який справді нічого не купував, отримує зірку як раніше.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Покупка за монети ламає ціль (як і раніше)
- [ ] Покупка за кристали ламає ціль
- [ ] Покупка за радіаційні монети ламає ціль
- [ ] Покупка за змішану ціну (кристали + радіація) ламає ціль
- [ ] Забіг без жодної покупки — ціль виконується
- [ ] Невдала спроба покупки (не вистачило валюти) ціль НЕ ламає
- [ ] Перший клік підтвердження другого ярусу (який ще нічого не купує) ціль НЕ ламає
- [ ] Ознака живе на забігу, а не в сумарній статистиці сейва
- [ ] Лишилось одне джерело правди — старої умови на монетному лічильнику більше немає
- [ ] Регресійний тест на покупку саме за кристали
- [ ] `node --test test/stars-unit.mjs` і `node test/smoke.mjs` зелені
