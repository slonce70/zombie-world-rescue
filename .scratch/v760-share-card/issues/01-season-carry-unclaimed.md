# 01 — Сезон заморожується замість переносити незабрану нагороду

**What to build:** борг рев'ю v752. Тікет 10 латки обіцяв патерн `weeklycamp.ensureWeeklyCamp`
(«переносить виконане й незабране»), а реалізовано інше — `src/season.js:95-105` при наявності
виконаної й незабраної сходинки **повертає старий сезон без змін**:

```js
const pending = seasonSteps(current.i | 0)
  .some((def) => !claimed.has(def.id) && gainedIn(save, current.base, def) >= def.target);
if (pending) return current;   // ← сезон просто не змінюється
```

Нагорода справді не згорає — червона лінія тримається, і це головне. Але дитина, яка закрила
сходинку й не тиснула «Забрати», лишається в Сезоні 1 нескінченно: нового сезону не буде,
поки не забере. Через рік на екрані так і висітиме «Сезон 1».

Треба зробити те, що обіцяв тікет: сезон котиться далі, а незабрані виконані нагороди
переїжджають у новий сезон і чекають там.
