# 04 — Мега-квест «3 титули» друкує по 5000 монет кожні дві доби

**What to build:** `ensureMegaQuests` у `src/progress.js:452-481` спершу рефрешить виконаний
квест (`q.progress = 0; q.done = false; q.doneAt = 0`), а потім **у тій самій ітерації** для
квестів із полем `current` перечитує значення з сейва:

```js
if (q.done && now - q.doneAt >= MEGA_QUEST_REFRESH_MS) { q.progress = 0; q.done = false; … }
if (!def.current) continue;
const current = Math.max(0, Math.min(def.target, def.current(save) | 0));
```

`titles3` (`src/progress.js:335`) рахує `save.titles.length`, а титули лише додаються й ніколи
не зникають. Тож одразу після рефрешу умова знову виконана, квест закривається і видає
**+5000 монет**.

Відтворено запуском модуля в пісочниці: перший виклик — 5000, через 48 год — 10 000,
ще через 48 — 15 000. Тригер — будь-яке відкриття панелі квестів або `onEvent` (тобто вбивство).
Умови тривіальні: рівень пасу ≥ 32 і три титули. Захисту від переводу годинника вперед тут
немає, на відміну від щоденних завдань.

Для масштабу: звільнення цілої країни дає ~1400 монет, найдорожча покупка коштує 4200.

Сам рефреш раз на дві доби — **задизайнена фіча**, на неї є тест `test/mega-season.mjs:96-114`.
Ламати його не можна. Баг — саме поєднання рефрешу з похідним `current`.
