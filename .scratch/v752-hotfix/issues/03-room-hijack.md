# 03 — Чужу кімнату можна перехопити у вікні реконекту хоста

**What to build:** `worker/relay-worker.js:178-182`, гілка `create=1`:

```js
if (create) {
  if (peers.has(1)) return new Response('taken', { status: 409 });   // єдина умова
  id = 1;
```

Перевіряється лише те, що слот хоста **зараз** не під'єднаний. Ні `alive`, ні `resumeKey`.
Коли хост згорнув вкладку, `webSocketClose` знімає pid 1 і ставить 30-секундний alarm —
і в цьому вікні будь-хто з кодом кімнати робить `?room=CODE&create=1`, дістає id 1,
а далі рядок ~209 **перезаписує секрет** `key:1`. Справжній хост зі старим ключем
не проходить перевірку, дістає pid ≥ 2 і сам себе вбиває.

Далі перехоплювач — авторитет: `src/net/client.js:157` приймає від `from === 1` усе,
включно зі станом, шкодою, нарахуваннями й вільним текстом у тостах.

Коди публічних кімнат видно всім через `/lobby/state`, і вони з чотирьох символів.

Іронія: коментар поруч (~:189) прямо обіцяє захист хоста від перехоплення — гілка `create`
обходить рівно його.

**Blocked by:** None — can start immediately.
