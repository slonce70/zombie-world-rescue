# 02 — Накрутка ліги стирає рекорди справжніх гравців

**What to build:** `/league/submit` у `worker/relay-worker.js:730-785` перевіряє лише діапазон
рахунку — ні підпису, ні токена, `cid` приходить із тіла. Анти-спам `_lastSubmit` ключований
`cid|mode|country`, тож ротація `cid` його обходить; лишається `_ipAllowed` — 20 запитів
за хвилину з адреси.

Сама накрутка місця для гри без грошей переживається. Не переживається інше: витіснення
понад 500 записів іде **за рангом**, а не за часом (`ORDER BY score … LIMIT -1 OFFSET 500`).
П'ятсот накручених результатів із максимальним балом виштовхують реальних дітей за межу
500-го місця — і їх записи видаляються назавжди, без відкату.

Після цього тікета накрутити своє місце все ще можна (це свідомо лишається клієнтською грою
за `TODO.md`), але **стерти чужі досягнення — ні**.

**Blocked by:** None — can start immediately.
