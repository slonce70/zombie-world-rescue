# 16 — Підказки місій кампанії теж друкують «E» на планшеті (корінь проблеми)

**What to build:** тікет 06 виправив `src/story/countryStories.js`, але корінь того самого бага
лишився в живому коді.

`src/missionpool.js:68-112` — конфіги `ACT_CFG` і `FETCH_CFG` оголошені як **модульні
константи**, тобто обчислюються в момент імпорту:

```js
const ACT_CFG = {
  lights: { …, prompt: t('Тримай {k} — засвіти ліхтар', { k: interactKey() }), … },
```

А `interactKey()` (`src/i18n.js:45`) читає `window.__game.input.touchMode` — на момент
завантаження модуля `window.__game` ще не існує, тож функція завжди повертає десктопний
варіант, і «E» **запікається в конфіг назавжди**. Перемикання на тач після старту вже нічого
не змінює.

Це не мертві дані: `ACT_CFG`/`FETCH_CFG` — підказки реальних місій кампанії («Засвіти
4 ліхтарі», «Розпали 3 багаття», «Розблокуй конвой», «Знайди балони для кулі», «Поверни
килими на базар», «Відкрий гробницю»). Планшетна дитина бачить у них клавішу, якої не має.

Виклики `interactKey()` **всередині функцій** (рядки 1090, 1098, 1154, 1439-1440, 1479-1484,
1536, 1580 та інші) працюють правильно — вони обчислюються під час гри. Проблема лише
в тих, що на верхньому рівні модуля.

Найдешевше правильне рішення: зробити ці поля лінивими (гетер на об'єкті літерала), щоб
місця споживання (`cfg.prompt`, `cfg.deliverPrompt`) не змінювались взагалі.
