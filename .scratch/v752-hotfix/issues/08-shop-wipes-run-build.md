# 08 — Покупка в магазині стирає бонуси карток драфту

**What to build:** обробники магазину **присвоюють** множники, перераховуючи їх із нуля
від `save.upgrades` і пасивок країн:

```js
case 'speed':  player.speedMult  = (1 + 0.1 * save.upgrades.speed) * (…sneakers…) * powers.speedMult; // shop.js:452
case 'damage': player.damageMult = (1 + 0.15 * save.upgrades.damage) * powers.damageMult;             // shop.js:454
```

А `src/runbuild.js` множить ті самі поля: `p.damageMult = Math.min(4, p.damageMult * 1.25)`
(`:18`), `p.speedMult = Math.min(1.8, p.speedMult * 1.12)` (`:37`).

Сценарій: дитина взяла картку «+40% шкоди» (множник 1 → 1.4), зайшла в магазин, купила
«Шкода» — множник став 1.15 замість 1.61. Механізму переприкладання немає: `runBuild.restore()`
кличеться лише на старті рівня.

Уточнення критика: стирають рівно три покупки — `speed` (`:452`), `damage` (`:454`)
і `sneakers` (`:630`). Аптечки, зброя, скіни й гаджети множників не чіпають.

**Критик знайшов додаткову грань, якої не було в первинній знахідці:** `applyGear`
(`src/player.js:320`) присвоює `jumpPower = (upgrades.sneakers ? 8.6 : 7.6) + …`, а картки
роблять `p.jumpPower += 1.2 / 2.2` (`runbuild.js:47,49`). Тож покупка жилета, шолома або
другого ярусу стирає бонус до стрибка.

Стираються також: ранговий множник спеціаліста, множник рівня бійця Експедиції
(`main.js:3959, :3970`) і кооп-роль scout (`main.js:4586`).
