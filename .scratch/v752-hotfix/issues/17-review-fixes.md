# 17 — Виправлення за рев'ю латки

**What to build:** рев'ю всієї латки від `d981dc0` знайшло дві речі, які треба закрити
до релізу.

## (а) Снаряди ловлять підлогу, що на метр ВИЩЕ за них — регресія тікета 05

`floorAt` (`src/world.js:2082`) писався для ніг гравця, і допуск `top <= y + 1.0` там —
це висота сходинки, на яку можна зійти. Тікет 05 підключив до цього ж методу снаряди:

```js
const rg = Math.max(this.world.groundH(rp.x, rp.z), this.world.floorAt(rp.x, rp.z, rp.y));
if (!boom && rp.y < rg + 0.15) boom = true;
```

Отже поверхня до метра **над** снарядом вважається землею.

Сценарії поломки:
- ракета базуки, випущена трохи вгору під навісом ринку (`world.js:446`, `top: gy + 2.9`;
  `world.js:1922`, `top: gy + 2.8`), детонує **в повітрі** приблизно за два метри під навісом;
- граната, кинута під поміст (`world.js:408-409`, вкладені `top: gy+1.18` і `gy+1.8`),
  **телепортується вгору** на верхній рівень і відскакує там.

Це рівно та сама скарга «граната не працює», заради якої писався тікет 05.

Галочка тікета 05 «підлога над головою не ловить снаряд» була сформульована неправильно:
гейт обмежує не «над головою», а «понад метр над головою». `test/projectile-floor-unit.mjs:41-42`
зафіксував цю поведінку як правильну — тест теж треба поправити.

Потрібен окремий, значно менший допуск для снарядів. Гравець і далі має сходити на сходинку
з допуском 1.0 — його поведінку не чіпати.

## (б) Стеля ліги 500 замикає таблицю назавжди

`worker/relay-worker.js:678` — `MAX_ENTRIES = 500`. Тікет 02 правильно прибрав видалення
чужих записів, але старий код тримав таблиці рівно на 500, тож кожна популярна пара
(режим, країна), яка вже стоїть на межі, після деплою **більше ніколи не прийме нового
гравця**. Протухання записів немає ніде.

Дитина ставить особистий рекорд у Штормі за Україну — і не потрапляє в таблицю ніколи,
без жодного повідомлення.

Оскільки нічого не видаляється, стеля потрібна лише як запобіжник від нескінченного росту.
Підняти її на порядки — Durable Object SQLite це витримує, а «замок» стає недосяжним.
